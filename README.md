# Mesa-A840

Mesa turnip driver builds for Qualcomm Adreno 8xx GPUs (targeting Adreno 840 / SM8850).

Built from the upstream Mesa 3D Graphics Library (https://gitlab.freedesktop.org/mesa/mesa).

## Builds

Prebuilt driver packages are published under Releases.
